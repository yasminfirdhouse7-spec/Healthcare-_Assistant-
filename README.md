# Healthcare-_Assistant-
Building an ai based assistant 
An AI-driven Symptom Analysis & Patient Management System
"Merging technology and healthcare to prioritize human life through logical decision-making."
📌 Project Overview
Healthcare Assistant is a C++ based diagnostic simulation tool designed to assist in preliminary health screenings. By utilizing a weighted scoring algorithm, the system evaluates the severity of common symptoms (COVID-19, Viral Infections, etc.) and provides instant risk assessment and medical advice.
