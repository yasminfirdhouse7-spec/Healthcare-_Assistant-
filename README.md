# Healthcare-_Assistant-
Building an ai based assistant 
An AI-driven Symptom Analysis & Patient Management System
"Merging technology and healthcare to prioritize human life through logical decision-making."
📌 Project Overview
Healthcare Assistant is a C++ based diagnostic simulation tool designed to assist in preliminary health screenings. By utilizing a weighted scoring algorithm, the system evaluates the severity of common symptoms (COVID-19, Viral Infections, etc.) and provides instant risk assessment and medical advice

 Key Features
Weighted Diagnosis: Assigns higher "weights" to critical symptoms like shortness of breath (3 pts) vs. minor symptoms like headaches (1 pt) to ensure accuracy.
Persistent Database: Uses C++ File I/O (fstream) to save patient history to patients.txt, allowing doctors/users to track health trends over time.
Real-time Risk Assessment: Calculates a "Confidence Percentage" based on the total severity score.
Input Validation: Robust error handling to prevent program crashes during data entry.
🛠️ Technical Stack
Language: C++
Core Concepts: Object-Oriented Logic, File Handling (I/O), Algorithmic Weighted Scoring, Time Management (ctime).
Tools: VS Code / G++ Compiler.
